Updating from a previous version?

If you're seeing the update notice in your app, download and run the installer. It installs alongside your existing copy — all your jobs, profiles, templates, and settings are preserved. The installer only replaces the application files.

What's new in v0.5.0: Plugin system for faster updates, export previews, document attachments, local network sharing, branded cover pages, digital signatures, exhibit hyperlinks, 15 export formats, expanded support chatbot (148 entries), and more.

Getting started

1

Download and install

Run the installer. Notare installs to your Documents folder and does not require administrator privileges. A desktop shortcut is created automatically.

2

Request a trial key

Use the contact form to request a free 7-day trial key. Include your name and email. Keys are issued within one business day.

3

Activate and start working

Launch Notare, enter your trial key when prompted, and you're ready. Set up a jurisdiction profile, upload your Word template, and create your first job.

System requirements

OS: Windows 10 or 11, 64-bit
RAM: 8 GB minimum, 16 GB recommended
Disk: ~3 GB for installation
GPU: NVIDIA GPU recommended for local transcription (optional)
Network: Required only for cloud engines and license activation
Browser: WebView2 Runtime (installed automatically)
