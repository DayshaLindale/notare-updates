Quick Reference — License Generation

When generating a license:
1. Select the tier code that matches what the customer purchased
2. Set duration: 7-days for trial, 365 for annual, 0 for unlimited (enterprise/internal)
3. The key format is auto-generated: NOTARE-XXXX-XXXX-XXXX
4. Send the key to the customer — they enter it once on first launch
5. Key validates locally against admin_data.json — no internet required after activation

To upgrade a customer:
1. Deactivate the old license in the Licenses tab
2. Generate a new license with the higher tier
3. Send the new key — they enter it in Settings

Master keys (enterprise, no expiry) should only be issued to company owners and internal staff.
